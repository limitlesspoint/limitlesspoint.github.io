# Limitless Point

Blog: https://limitlesspoint.github.io/

Writing desk: https://app.pagescms.org/

## Write a post

Open Pages CMS, choose `limitlesspoint.github.io`, then **Posts → Add**.
Enter a title and your writing, then save. The date is filled automatically.
Saved posts appear on the blog after GitHub finishes publishing, usually within a few minutes.
Use the editor's image button to upload pictures.

The repository is public. Saving writes publicly visible files; this is not private draft storage.
For private work in progress, keep your draft in your own writing app until ready to publish.

The blog uses GitHub's built-in Jekyll hosting and Minima theme. Hosting, formatting,
post lists, RSS and the publishing process are already configured.
